Applied NumPy Projects

This repository contains a collection of mini projects implemented using only NumPy.
The goal of this repository is to strengthen understanding of numerical computing, matrix operations, and core mathematical concepts using efficient array-based programming.

All projects are built without external libraries (such as pandas, scikit-learn, or matplotlib) to focus purely on NumPy fundamentals.

🎯 Objectives

Practice numerical computing using NumPy

Implement logic using array operations

Understand matrix manipulation and vectorization

Build strong foundations for Machine Learning

🛠️ Technologies Used

Python

NumPy

🧠 Concepts Covered

Array creation and manipulation

Matrix operations

Broadcasting

Linear algebra

Statistical computations

Logical validation using arrays

📂 Projects Included

Sudoku Validator

Student Marks Analyzer

Matrix Calculator

Linear Regression (from scratch)

Basic Image Processing (grayscale operations)

This repository serves as a foundation for advanced topics such as:
